# Code of conduct / Правила общения

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Be respectful in issues, discussions and pull requests. Personal attacks, harassment and spam are removed, and repeat offenders are blocked. Report problems to the maintainer through a private [security advisory](https://github.com/olerast67/steady-volume/security/advisories/new) or on [Boosty](https://boosty.to/olerast).

Проект следует [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). В issue, обсуждениях и pull request общайтесь уважительно. Оскорбления, травля и спам удаляются, за повторные нарушения автор блокирует. Сообщить о проблеме автору можно через приватный [security advisory](https://github.com/olerast67/steady-volume/security/advisories/new) или на [Boosty](https://boosty.to/olerast).
