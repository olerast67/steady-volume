# Changelog / История изменений

## 1.2.1 (2026-10-10)

- The popup shows the author (olerast.com) and a GitHub button; the extension details page links to the repository.
- В окне расширения появились автор (olerast.com) и кнопка GitHub, на странице расширения в браузере есть ссылка на репозиторий.

## 1.2.0 (2026-10-10)

- The popup is translated into 18 languages; the store name and description follow the browser language.
- Окно расширения переведено на 18 языков, название и описание в магазинах показываются на языке браузера.

## 1.1.0 (2026-10-10)

- Video from servers on another domain without CORS permission is connected: the extension adds CORS headers for the pair of that page and that server, only for media requests. Embedded VK Video players on other sites work.
- Players inside Shadow DOM, closed ones included, are found.
- Chromium browsers: whole-tab sound processing for DRM-protected video and players that can't be connected directly. Starts from the popup, with a button, or with Alt+Shift+V.
- Separate packages for Chromium and Firefox.
- Подключаются видео с серверов на другом домене без разрешения CORS: расширение добавляет заголовки CORS для пары «страница и сервер», только для медиазапросов. Работают встроенные плееры VK Видео на других сайтах.
- Расширение находит плееры внутри Shadow DOM, в том числе закрытого.
- Браузеры на Chromium: обработка звука всей вкладки для видео с DRM и плееров, к которым нельзя подключиться напрямую. Включается из окна расширения, кнопкой или сочетанием Alt+Shift+V.
- Отдельные архивы для Chromium и Firefox.

## 1.0.0 (2026-10-10)

- Volume boost up to 600%, leveling modes Off, Light, Auto and Night, fine-tuning of the compressor and limiter, Clearer speech, per-site switch.
- Усиление до 600%, режимы выравнивания «Выкл», «Мягко», «Авто» и «Ночь», тонкая настройка компрессора и лимитера, «Чётче речь», выключатель для сайта.
