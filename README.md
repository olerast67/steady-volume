# Ровный звук

[![Релиз](https://img.shields.io/github/v/release/olerast67/steady-volume?label=%D0%B2%D0%B5%D1%80%D1%81%D0%B8%D1%8F)](https://github.com/olerast67/steady-volume/releases/latest)
[![Лицензия MIT](https://img.shields.io/badge/license-MIT-green)](LICENSE)
![Chrome, Edge, Яндекс Браузер, Opera, Brave, Firefox](https://img.shields.io/badge/Chrome%20%7C%20Edge%20%7C%20Yandex%20%7C%20Opera%20%7C%20Firefox-supported-blue)

[English](README.en.md)

Расширение для браузера, которое усиливает звук видео до 600% и выравнивает громкость. Тихие диалоги в фильмах поднимаются, взрывы и музыка опускаются, лимитер на выходе не даёт усиленному звуку хрипеть. Работает в Chrome, Edge, Яндекс Браузере, Opera, Brave и Firefox, обрабатывает звук внутри браузера и ничего никуда не отправляет.

![Окно расширения поверх ролика на YouTube в Firefox, режим «Авто»](docs/screenshot-youtube.jpg)

Я сделал его для фильмов и сериалов в браузере. Разговоры в них записаны тихо, а экшен громко, и при просмотре дома я всё время крутил громкость.

## Как пользоваться

1. Поставьте расширение по инструкции ниже.
2. Включите видео. Расширение подключится само в режиме «Авто», настраивать ничего не нужно.
3. Если звук всё равно тихий, сдвиньте ползунок «Громкость». Ночью включите режим «Ночь».

Если расширение не может подключиться к видео напрямую, например на сайте с защитой DRM, в Chrome, Edge, Яндекс Браузере, Opera и Brave оно обрабатывает звук всей вкладки. Захват включается сам при открытии окна расширения, кнопкой «Обрабатывать звук всей вкладки» или сочетанием Alt+Shift+V.

Окно расширения открывается по значку на панели браузера. Если значка не видно, нажмите на значок пазла справа от адресной строки и закрепите «Ровный звук».

## Установка

Пока расширение проходит проверку в магазинах, его можно поставить из архива. Это занимает около минуты.

### Chrome, Edge, Яндекс Браузер, Opera, Brave

1. Скачайте `steady-volume-<версия>-chromium.zip` со страницы [последнего релиза](https://github.com/olerast67/steady-volume/releases/latest) и распакуйте в папку, которую не будете удалять. Если папку удалить, расширение пропадёт из браузера.
2. Откройте страницу расширений. Адрес нужно вставить в адресную строку:

   | Браузер | Адрес |
   |---|---|
   | Chrome, Brave | `chrome://extensions` |
   | Edge | `edge://extensions` |
   | Яндекс Браузер | `browser://extensions` |
   | Opera | `opera://extensions` |

3. Включите «Режим разработчика». В Chrome переключатель находится справа вверху, в Edge слева внизу.
4. Нажмите «Загрузить распакованное расширение» и выберите распакованную папку, в которой лежит `manifest.json`.

При каждом запуске Chrome предлагает отключить расширения в режиме разработчика. Нажмите «Отмена» или закройте окно. Когда расширение появится в Chrome Web Store, ссылка будет здесь, и установка займёт одно нажатие.

### Firefox

Нужен Firefox 140 или новее. Firefox ставит из файла только расширения, подписанные Mozilla. Подписанный файл `.xpi` появится в релизах после проверки на addons.mozilla.org. До этого расширение можно загрузить на время, до перезапуска браузера: скачайте `steady-volume-<версия>-firefox.zip`, распакуйте, откройте `about:debugging` → «Этот Firefox» → «Загрузить временное дополнение» и выберите `manifest.json`.

## Режимы и настройки

| Настройка | Что делает |
|---|---|
| Громкость | Усиление от 100% до 600% (до +15,6 дБ) поверх выравнивания. Пики срезает лимитер |
| Выравнивание | Выкл, Мягко, Авто, Ночь. Режим «Авто» включён по умолчанию |
| Чётче речь | Минус 4 дБ ниже 160 Гц и плюс 4 дБ около 2,8 кГц |
| На этом сайте | Выключает обработку на текущем сайте. Видео, которое уже играет, переключается без перезагрузки |

| Режим | Для чего | Подъём тихого, до | Снижение громкого, до | Компрессор |
|---|---|---|---|---|
| Выкл | Только усиление, динамика остаётся как в записи | 0 | 0 | выключен |
| Мягко | Музыка и клипы | +6 дБ | −6 дБ | порог −16 дБ, 2:1 |
| Авто | Фильмы, сериалы, YouTube | +12 дБ | −12 дБ | порог −22 дБ, 3:1 |
| Ночь | Тихий просмотр ночью, шумная комната | +20 дБ | −20 дБ | порог −28 дБ, 6:1 |

В разделе «Тонкая настройка» семь ползунков: целевая громкость (от −30 до −12 LUFS), подъём тихого и снижение громкого (до 24 дБ), время возврата громкости (0,5-6 с), порог и степень сжатия компрессора, потолок лимитера (от −12 до 0 дБ). После любого изменения режим становится «свои настройки». Кнопка «Сбросить всё» возвращает «Авто», 100% и выключает «Чётче речь».

Окно расширения переведено на 18 языков: русский, английский, украинский, немецкий, французский, испанский, итальянский, португальский (Бразилия), польский, турецкий, японский, корейский, китайский упрощённый и традиционный, индонезийский, вьетнамский, хинди и арабский. Язык берётся из настроек браузера. Переводы, кроме русского и английского, сделаны нейросетью, исправления принимаются в `scripts/locales.py`.

## Как устроена обработка

Расширение ждёт, когда на странице начнёт играть `<video>` или `<audio>`, и подключает элемент к цепочке Web Audio. В каждом фрейме страницы цепочка своя:

1. Фильтры режима «Чётче речь».
2. Автоматическая регулировка усиления. Каждые 100 мс расширение измеряет громкость за последние 400 мс с K-взвешиванием по ITU-R BS.1770 и плавно ведёт её к −20 LUFS. Громкость опускается с постоянной времени 0,2-0,5 с, поднимается за 1,5-3 с. Если громкость ниже −50 LUFS, усиление остаётся прежним, чтобы тишина и шум не поднимались.
3. Компрессор `DynamicsCompressorNode` для коротких скачков, которые регулировка не успевает поймать.
4. Усиление из ползунка «Громкость».
5. Лимитер с потолком −2 дБ и мягкое ограничение выше 0,8 от полной шкалы.

Я собрал цепочку только из встроенных узлов Web Audio и отказался от `AudioWorklet`. Модуль `AudioWorklet` загружается отдельным скриптом, и на сайтах со строгой политикой CSP, например на YouTube, браузер может его заблокировать.

Многие плееры берут файл видео с сервера раздачи (CDN) на другом домене. Браузер даёт обработать звук такого файла, только если ответ сервера разрешает это заголовками CORS. Расширение добавляет эти заголовки правилом `declarativeNetRequest`. Правило действует только для пары «этот сайт и этот сервер» и только для запросов, которые делают элементы `<video>` и `<audio>`. После этого расширение перезагружает видео с атрибутом `crossorigin` с той же секунды и подключает его к обработке. Так работают встроенные плееры VK Видео на других сайтах.

Плееры-веб-компоненты прячут `<video>` внутри Shadow DOM, туда не доходят события страницы. Расширение находит такие плееры, в том числе в закрытом Shadow DOM, раз в 2 секунды и при запуске видео.

Видео с защитой DRM браузер отдаёт расширениям тишиной. В браузерах на Chromium для таких случаев есть захват звука всей вкладки через `tabCapture`. Пока захват включён, вкладка звучит только через расширение: звук идёт в отдельный документ расширения, проходит ту же цепочку и выходит в колонки. Firefox захват вкладки не поддерживает.

## Где работает и где нет

| Что играет | Chromium (Chrome, Edge, Яндекс, Opera, Brave) | Firefox |
|---|---|---|
| YouTube, плееры на HLS и DASH | да | да |
| Файлы с CDN на другом домене, встроенные плееры VK Видео | да | да |
| Плееры в Shadow DOM | да | да |
| Видео с защитой DRM (Netflix, платные онлайн-кинотеатры) | через захват вкладки | нет |
| Звук без `<video>` и `<audio>` (браузерные игры, сайты со своей обработкой Web Audio) | через захват вкладки | нет |
| Звонки и голосовые чаты (Google Meet, Discord) | расширение их пропускает | расширение их пропускает |
| Служебные страницы браузера и магазины расширений | нет | нет |

Захват вкладки я проверил на тестовом видео dash.js с шифрованием ClearKey. Это тот же механизм EME, на котором работает защита Netflix и онлайн-кинотеатров, но с открытым ключом. На самом Netflix и Кинопоиске я его не проверял. Встроенные плееры VK Видео я проверял по устройству их запросов: живой плеер VK показывает автоматическому браузеру проверку на бота.

Если звук на сайте пропал, выключите расширение для этого сайта переключателем «На этом сайте», перезагрузите страницу и откройте issue с адресом страницы.

## Вопросы

Работает ли на Netflix или Кинопоиске? В браузерах на Chromium должно работать через захват вкладки: откройте окно расширения во время просмотра, захват включится сам. На этих сервисах я его не проверял. В Firefox нет. Там подойдёт обработка звука на уровне системы: в Windows это «Тонкомпенсация» в свойствах динамиков или Equalizer APO с компрессором.

Работает ли на телефоне? Манифест поддерживает Firefox для Android 142 и новее. На телефоне я расширение не проверял.

Отстаёт ли звук от картинки? Обработка Web Audio добавляет задержку вывода звука, при захвате вкладки задержка больше. Я её не замерял, на тестовых видео рассинхрон на слух не заметен.

Зачем доступ ко всем сайтам? Видео бывает на любом сайте и во встроенных плеерах с других доменов. Расширение читает на странице только элементы `<video>` и `<audio>`, а правила заголовков CORS нужны для серверов, с которых плееры грузят видео.

## Приватность

Расширение не собирает данные и само не делает сетевых запросов. Настройки хранятся в `storage.sync` браузера, правила заголовков CORS живут до закрытия браузера. Захваченный звук вкладки обрабатывается и сразу выводится в колонки, расширение его не записывает. Подробнее в [PRIVACY.md](PRIVACY.md).

| Разрешение | Зачем |
|---|---|
| `storage` | Хранит громкость, режим и список выключенных сайтов |
| `activeTab` | Окно расширения узнаёт адрес открытой вкладки для переключателя «На этом сайте» |
| Доступ ко всем сайтам (`<all_urls>`) | Скрипт подключает к обработке элементы `<video>` и `<audio>` на любом сайте и во встроенных плеерах |
| `declarativeNetRequestWithHostAccess` | Добавляет заголовки CORS к ответам сервера с видео, чтобы браузер дал обработать его звук |
| `tabCapture`, `offscreen` (только Chromium) | Захват звука вкладки для видео с DRM и сайтов, к плеерам которых нельзя подключиться напрямую |

## Проверка

Тестовый стенд `test/harness.html` прогоняет синтетический «фильм» через цепочку в `OfflineAudioContext`: 12 с тихого диалога, 12 с громкого экшена со взрывами, 12 с диалога. Громкость в таблице это медиана среднеквадратичного уровня по окнам 400 мс, в дБ от полной шкалы, при громкости 100%.

| Режим | Диалог | Экшен | Разница | Пик |
|---|---|---|---|---|
| Без расширения | −40,9 | −24,8 | 16,1 дБ | +0,7 дБ |
| Выкл | −41,1 | −24,8 | 16,2 дБ | −1,4 дБ |
| Мягко | −33,9 | −23,5 | 10,4 дБ | −1,2 дБ |
| Авто | −25,2 | −21,4 | 3,8 дБ | −1,2 дБ |
| Ночь | −22,8 | −19,8 | 3,0 дБ | −2,7 дБ |

Сквозные тесты ставят расширение в браузер и проигрывают тот же файл. Я запускал их на Windows 10 в Edge 155 (`test/e2e.mjs`, `test/e2e-capture.mjs`) и Firefox 157 (`test/e2e-firefox.mjs`). Тесты проверяют подъём тихого диалога и снижение громкого экшена. Видео с чужого сервера с CORS и без него должно подключиться, продолжить играть с той же секунды, и уровень звука на входе обработки должен быть выше −50 LUFS. Плеер в закрытом Shadow DOM тоже должен подключиться. Ещё тесты переключают сайт и тонкую настройку из окна расширения и включают и выключают захват вкладки. Захват вкладки я дополнительно проверил на видео с шифрованием ClearKey из примеров dash.js. На YouTube в Edge 155 расширение подключилось к видео и снизило громкий ролик на 4 дБ.

```bash
npm install
node test/make-movie.mjs     # тестовый файл test/movie.wav
node test/e2e.mjs msedge     # или chrome, chromium
node test/e2e-capture.mjs msedge
npm run lint && node test/e2e-firefox.mjs
npm run serve                # стенд: http://127.0.0.1:8765/test/harness.html
```

## Сборка

```bash
npm run lint    # сборка build/chromium и build/firefox, проверка Firefox-версии через web-ext
npm run build   # архивы dist/steady-volume-<версия>-chromium.zip и -firefox.zip
```

`src/manifest.json` написан для Chromium. Скрипт `scripts/build.mjs` делает из него версию для Firefox: фоновый скрипт без service worker, без `tabCapture`, `offscreen` и сочетания клавиш. При публикации тега `v*` GitHub Actions собирает архив и прикладывает его к релизу. Если в секретах репозитория есть ключи AMO, тот же процесс подписывает `.xpi` для Firefox. Порядок публикации в магазинах описан в [docs/publishing.md](docs/publishing.md).
