# Ровный звук

[English](README.en.md)

Расширение для браузеров на Chromium (Chrome, Edge, Яндекс Браузер, Opera, Brave) и для Firefox. Оно усиливает звук видео и аудио на сайтах до 600% и выравнивает громкость: тихие диалоги поднимаются, громкие сцены опускаются, а лимитер на выходе не даёт звуку хрипеть. Вся обработка идёт в браузере, данные никуда не отправляются.

![Окно расширения](docs/popup-test.png)

Я сделал его для фильмов и сериалов в браузере. В них разговоры записаны тихо, а музыка и взрывы громко, и при просмотре дома приходится всё время крутить громкость.

## Установка

Пока расширение не опубликовано в магазинах, его можно поставить из архива со страницы [Releases](https://github.com/Erop404iv/steady-volume/releases).

### Chrome, Edge, Яндекс Браузер, Opera, Brave

1. Скачайте `steady-volume-<версия>.zip` и распакуйте в папку, которую не будете удалять.
2. Откройте страницу расширений: `chrome://extensions` в Chrome и Brave, `edge://extensions` в Edge, `browser://extensions` в Яндекс Браузере, `opera://extensions` в Opera.
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите папку, в которой лежит `manifest.json`.

Браузер будет напоминать о режиме разработчика при запуске. После публикации в Chrome Web Store установка будет в одно нажатие.

### Firefox

Нужен Firefox 140 или новее. Firefox ставит из файла только подписанные расширения. Подписанный `.xpi` появится в Releases после проверки на addons.mozilla.org. До этого расширение можно загрузить временно, до перезапуска браузера: `about:debugging` → «Этот Firefox» → «Загрузить временное дополнение» → `manifest.json` из распакованного архива.

## Настройки

| Настройка | Что делает |
|---|---|
| Громкость | Усиление от 100% до 600% (до +15,6 дБ). Стоит после выравнивания, пики срезает лимитер |
| Выравнивание | Выкл, Мягко, Средне, Сильно. Чем сильнее режим, тем меньше разница между тихими и громкими сценами (цифры в таблице ниже) |
| Чётче речь | Минус 4 дБ ниже 160 Гц и плюс 4 дБ около 2,8 кГц |
| На этом сайте | Выключает обработку на текущем сайте. Видео, которое уже играет, переключается без перезагрузки страницы |

| Режим | Подъём тихого, до | Снижение громкого, до | Компрессор |
|---|---|---|---|
| Мягко | +6 дБ | −6 дБ | порог −16 дБ, 2:1 |
| Средне | +12 дБ | −12 дБ | порог −22 дБ, 3:1 |
| Сильно | +20 дБ | −20 дБ | порог −28 дБ, 6:1 |

## Как устроена обработка

Расширение ждёт, когда на странице начнёт играть `<video>` или `<audio>`, и подключает элемент к цепочке Web Audio. В каждом фрейме страницы цепочка своя:

1. Фильтры режима «Чётче речь».
2. Автоматическая регулировка усиления. Каждые 100 мс расширение измеряет громкость за последние 400 мс с K-взвешиванием по ITU-R BS.1770 и плавно ведёт её к −20 LUFS. Громкость опускается с постоянной времени 0,2-0,5 с, поднимается за 1,5-3 с. Если громкость ниже −50 LUFS, усиление остаётся прежним, чтобы тишина и шум не поднимались.
3. Компрессор `DynamicsCompressorNode` для коротких скачков, которые регулировка не успевает поймать.
4. Усиление из ползунка «Громкость».
5. Лимитер с порогом −2 дБ и мягкое ограничение выше 0,8 от полной шкалы.

Я собрал цепочку только из встроенных узлов Web Audio и отказался от `AudioWorklet`. Модуль `AudioWorklet` загружается отдельным скриптом, и на сайтах со строгой политикой CSP, например на YouTube, браузер может его заблокировать.

## Где расширение не работает

- Видео с защитой DRM, например на Netflix. Звук такого видео браузер отдаёт расширению тишиной, поэтому расширение такие видео не подключает, и они играют без обработки.
- Видео, которое грузится с другого сервера без разрешения CORS. Подключение такого видео выключило бы его звук, и расширение его пропускает. В окне расширения появляется пояснение.
- Звонки и голосовые чаты (Google Meet, Discord): элементы с потоком WebRTC расширение не трогает.
- Сайты, которые сами подключают видео к своей обработке Web Audio.
- Звук, который сайт играет без `<video>` и `<audio>`, например в браузерных играх.
- Служебные страницы браузера и магазины расширений.

Если звук на сайте пропал, выключите расширение для этого сайта и перезагрузите страницу.

## Приватность

Расширение не собирает данные и не делает сетевых запросов. Настройки хранятся в `storage.sync` браузера. Подробнее в [PRIVACY.md](PRIVACY.md).

| Разрешение | Зачем |
|---|---|
| `storage` | Хранит громкость, режим выравнивания и список выключенных сайтов |
| `activeTab` | Окно расширения узнаёт адрес открытой вкладки для переключателя «На этом сайте» |
| Скрипт на всех сайтах (`<all_urls>`) | Видео встречается на любом сайте и во встроенных плеерах, скрипт подключает к обработке элементы `<video>` и `<audio>` |

## Проверка

Тестовый стенд `test/harness.html` прогоняет синтетический «фильм» через цепочку в `OfflineAudioContext`: 12 с тихого диалога, 12 с громкого экшена со взрывами, 12 с диалога. Громкость в таблице это медиана среднеквадратичного уровня по окнам 400 мс, в дБ от полной шкалы. На входе диалог звучит на −40,9 дБ, экшен на −24,8 дБ, разница 16,1 дБ.

| Режим | Диалог | Экшен | Разница | Пик |
|---|---|---|---|---|
| Без обработки | −40,9 | −24,8 | 16,1 дБ | +0,7 дБ |
| Выравнивание выкл, 100% | −40,0 | −23,6 | 16,3 дБ | −0,55 дБ |
| Мягко | −32,9 | −22,4 | 10,5 дБ | −0,43 дБ |
| Средне | −24,0 | −20,2 | 3,8 дБ | −0,46 дБ |
| Сильно | −21,6 | −18,7 | 2,9 дБ | −1,53 дБ |

Сквозные тесты ставят расширение в браузер и проигрывают тот же файл. Я запускал их на Windows 10 в Edge 155 (`test/e2e.mjs`) и Firefox 157 (`test/e2e-firefox.mjs`). Тесты проверяют, что тихий диалог поднимается, громкий экшен опускается, видео с другого сервера без CORS играет без обработки и со звуком. Ещё они проверяют, что переключатель сайта срабатывает без перезагрузки. На YouTube в Edge 155 расширение подключилось к видео и снизило громкий ролик на 4 дБ.

```bash
npm install
node test/make-movie.mjs     # тестовый файл test/movie.wav
node test/e2e.mjs msedge     # или chrome, chromium
node test/e2e-firefox.mjs
npm run serve                # стенд: http://127.0.0.1:8765/test/harness.html
```

## Сборка

```bash
npm run lint    # проверка манифеста и кода через web-ext
npm run build   # архив в dist/, один и тот же для всех браузеров
```

Один `manifest.json` подходит для Chromium и Firefox: блок `browser_specific_settings` Chromium пропускает. При публикации тега `v*` GitHub Actions собирает архив и прикладывает его к релизу. Если в секретах репозитория есть ключи AMO, тот же процесс подписывает `.xpi` для Firefox.
