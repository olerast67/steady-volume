# Security policy / Безопасность

Please report vulnerabilities privately through [Security → Report a vulnerability](https://github.com/olerast67/steady-volume/security/advisories/new): the report stays visible only to the maintainer until a fix is out. Only the latest release is supported.

The extension runs on all sites, adds CORS headers to media responses (for one page host and one media host at a time) and, in Chromium browsers, can capture a tab's sound. Reports about any of these reaching data they shouldn't are especially welcome.

Об уязвимостях сообщайте приватно через [Security → Report a vulnerability](https://github.com/olerast67/steady-volume/security/advisories/new): такое сообщение видит только автор, пока не выйдет исправление. Поддерживается только последний релиз.

Расширение работает на всех сайтах, добавляет заголовки CORS к ответам с медиафайлами (для одной пары «страница и сервер» за раз) и в браузерах на Chromium может захватывать звук вкладки. Сообщения о том, что что-то из этого даёт доступ к лишним данным, особенно нужны.
